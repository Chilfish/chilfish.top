# 2026-09-12

## 存量问题清理：静默失效的三处缺口

**背景**：例行盘点「这个站现在还能干什么」，实测构建与产物后发现三处「代码在、功能不在」的缺口，统一处理。根因分析见 [postmortem/001](../postmortem/001-silent-failure.md)。

### 修复

| 问题                                                                 | 处理                                                                                                                                      |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| RSS 从未产出（`_GET` 未导出且无路由）                                | 新建 `src/pages/feed.ts`，`export const GET`；文章链接由 `/blog/<slug>/` 修正为 `/posts/<slug>/`；`excludes` tag 过滤改为排除命中任一 tag |
| 列表/标签/归档页输出 `article:published_time="Invalid Date"`         | `Head.astro` 改为仅在日期有效时输出 `article:*`，并使用 ISO 字符串；文章页 `modifiedTime` 优先取 `modifiedDate`                           |
| `[type]/[...page].astro` 残留调试 `Astro.redirect()` + `console.log` | 移除（该重定向在 `prerender = true` 下被 Astro 静默忽略，只在构建日志刷噪音）                                                             |

### 删除（弃用即删除，不留注释）

- `PostMeta.astro`、`archives.astro` 中的注释代码块
- 全仓零引用的 `src/components/post/LatestBlogs.astro`
- 空壳端点 `src/pages/api/endpoint.ts`
- `src/utils/feed.ts`（迁移为路由 `src/pages/feed.ts`）

### 追加：构建修复与调试输出清理

收尾验证时 build 报 `MISSING_EXPORT "localImgHost"`——`src/constant/config.ts` 已改为图床固定远程地址（`isDev` / `localImgHost` 移除），但 `src/plugins/rehype-image.ts` 仍引用二者。按既定方向（不再做本地图床替换）处理：

- `rehype-image.ts`：删除 `isDev` 分支与 config import，`src` 改为 `const`
- `src/constant/config.ts`：删除已无引用的 `isDev` 与注释掉的 `localImgHost`
- `src/constant/index.ts`：删除末尾遗留的 `console.log(total)`（`total` 仅服务于该行）

### 决策

1. **阅读时长 / 字数统计**：功能未启用，选择直接删除而非补完（用户决策）。
2. **`LatestBlogs.astro`**：零引用，选择删除而非挂到首页（用户决策）。
3. **RSS 落在 `src/pages/` 而非 `src/utils/`**：`unplugin-auto-import` 会把工具目录的导出注册为全局变量，导出 `GET` 会污染全局类型。记录为 [ADR-007](../planning/architecture.md#adr-007rss-作为路由文件而非工具函数)。
4. **RSS 保持按需渲染**：URL 为 `/feed`，与 `vercel.json` 既有缓存头一致。
