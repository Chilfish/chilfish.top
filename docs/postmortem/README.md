## 高频雷区（写码前自查）

> 下表为基于本技术栈（Astro SSG + Vue island + UnoCSS）**预登记**的潜在雷区。踩坑次数为累计，触发后转正式 postmortem 并计入；阈值 = 再犯 N 次即升级处理。

### 1. Astro SSG / 组件

| 规则                                              | 踩坑次数    | 阈值 | 对策                                             |
| ------------------------------------------------- | ----------- | ---- | ------------------------------------------------ |
| 渲染期访问 `window` / `document`                  | 0（预登记） | 1    | `onMounted` / 客户端脚本，见 code-style 禁止事项 |
| Vue island props 传复杂对象（Date / 函数）        | 0（预登记） | 1    | 用序列化数据（ISO 字符串 / 纯对象）              |
| `.astro` 中塞交互逻辑                             | 0（预登记） | 1    | 拆成 `.vue` island                               |
| 新增组件不兼容 dark mode                          | 0（预登记） | 1    | 复用 SCSS 变量，参考 `useDark`                   |
| 预渲染页面中的 `Astro.redirect()` 被静默忽略      | 1（PM 001） | 1    | 调试残留一律移除；重定向只走 `[...all].ts`       |
| 元信息用未校验的日期构造（`new Date(undefined)`） | 1（PM 001） | 1    | 构造前校验有效性，无则不输出该字段               |

### 2. 内容与构建

| 规则                                         | 踩坑次数    | 阈值 | 对策                                        |
| -------------------------------------------- | ----------- | ---- | ------------------------------------------- |
| `draft: true` 未去除 → 文章不发布            | 0（预登记） | 1    | 发布前检查 frontmatter                      |
| content schema 变更 → 旧文章缺字段构建失败   | 0（预登记） | 1    | 变更前 `astro check`，字段给默认值          |
| 动态拼接 UnoCSS 类名不生效                   | 0（预登记） | 1    | 用静态完整类名 / `uno.config.ts` 安全列表   |
| 端点未 `export`（如写成 `_GET`）→ 静默不生成 | 1（PM 001） | 1    | 路由文件必须 `export const GET`，并实测请求 |
| 已弃用功能以注释形式留存 → 与已实现不可区分  | 1（PM 001） | 1    | 弃用即删除，不在仓库留注释代码              |
